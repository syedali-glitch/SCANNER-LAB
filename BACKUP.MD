# Scanner Lab - PROJECT BACKUP & SPECIFICATIONS

## 1. Overview
Scanner Lab is a premium, high-performance Android utility app designed for high-end document processing. It focuses on privacy (local processing), speed, and a Dark Premium aesthetic with glassmorphism elements.

## 2. Core Functions
- **Document Scanner**: Native camera integration with ML Kit based edge detection and custom saturation/contrast filters ("Magic Filter"). Generates PDFs locally.
- **Advanced PDF Tools**:
  - **Merge**: Combining multiple PDF files into one.
  - **Split**: Dividing a PDF into individual pages or ranges.
- **File Converter**:
  - **OCR Integration**: Extracts text from images using ML Kit.
  - **Formats**: Supports Image to PDF, Image to Excel (using Apache POI), and Image to Word (Logic implemented).
- **File Viewer**: Centralized hub to view and manage generated documents (PDF, XLS, DOC) with real-time search and type filtering.

## 3. Technical Dependencies
- **UI Framework**: Material Design 3 (M3) with custom Teal/Cyan theme.
- **Networking**: AdMob SDK (Banner integration).
- **Logic & Processing**:
  - **ML Kit**: Barcode Scanning, Text Recognition.
  - **CameraX**: High-performance camera preview and capture.
  - **OpenPDF**: Lightweight, privacy-friendly PDF manipulation (Merging/Splitting).
  - **Apache POI**: Industry-standard library for creating Excel (.xlsx) and Word (.docx) documents.
  - **Coroutines & Lifecycle**: Scoped background processing for UI safety.
  - **ViewBinding**: Type-safe layout access.

## 4. User Criteria & UX Design
- **Theme**: "Dark Premium" - Deep blacks, glowing teal gradients, and glassmorphism (frosted glass overlays).
- **Navigation**: 3-item Bottom Nav (Home, History, Settings).
- **Settings**: Centralized control for permissions and notifications. Includes company info for **Plainlabs**.
- **User Feedback**: Pulse animations on interaction, haptic feedback, and clear progress indicators during heavy processing.

## 5. UI/UX Strategy (Plainlabs Pattern)
- Buttons and arrows feature distinct black outlines to contrast against high-glow gradients, providing a professional, "non-cheap" look.
- CoordinatorLayout used for smooth AppBar collapsing and nested scrolling.
