# Scanner Lab
A premium document scanner and PDF utility app for Android.

## Features
- **Document Scanner**: Native PDF generation with edge detection and filters.
- **PDF Tools**: Merge, Split, and Compress PDFs.
- **File Converter**: Convert Images to Excel/PDF/Word transparently.
- **File Viewer**: Built-in viewer for documents.
