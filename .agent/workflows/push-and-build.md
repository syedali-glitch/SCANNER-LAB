description: Push changes to git and trigger a build via GitHub Actions workflow
---

1. Check if the directory is a git repository: `git status`
2. If not, initialize: `git init`
3. Add remote if missing: `git remote add origin https://github.com/syedali-glitch/SCANNER-LAB`
4. Stage all changes: `git add .`
5. Commit changes: `git commit -m "Update project"`
6. Push to master: `git push -u origin master`
